# Øvelser: andre representasjoner

1. Bruk `g = b XOR (b >> 1)` på binærverdien `0110`.
2. Hvorfor kan én-bit-overganger være nyttige i en mekanisk posisjonsenkoder?
3. Med excess-127: hvilken virkelig eksponent representerer feltverdien 140?
4. Med excess-15: hvilken feltverdi lagrer eksponenten −4?
5. Hva er ASCII-kodeverdien til `A` i desimal og hex?
6. Forklar forskjellen mellom et Unicode code point og UTF-8-byte.
7. Et register bruker bit 7 som READY og bit 0 som ENABLE. Hvilken maske tester begge bitene samtidig?
8. Gi tre forskjellige plausible tolkninger av byte `0x41`.
