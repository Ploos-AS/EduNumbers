# Øvelser: heltallsrepresentasjon

1. Finn unsigned-området for 10 bit.
2. Tolk `FE₁₆` som unsigned 8-bit og signed 8-bit toerkomplement.
3. Skriv −42 som 8-bit toerkomplement i binær og hex.
4. Hva blir `250 + 20` dersom bare åtte bit beholdes?
5. Forklar forskjellen mellom carry og signed overflow.
6. Hvorfor kan signed 8-bit representere −128, men ikke +128?
7. Hva blir `7F₁₆ + 01₁₆` som signed 8-bit, og hvorfor er resultatet problematisk?
