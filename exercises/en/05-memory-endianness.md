# Exercises: memory and endianness

1. A 64-bit value starts at `0x2008`. Which byte addresses does it use?
2. Calculate `0x4000 + 0x01A7`.
3. How many byte addresses exist in a 20-bit byte-addressed address space?
4. Write `0xCAFEBABE` as four bytes in big-endian.
5. Write the same value in little-endian.
6. A dump contains `34 12`. Interpret it as one unsigned 16-bit value in both little- and big-endian.
7. Why can you not determine the meaning of four raw bytes from their bit patterns alone?
8. Explain the difference between alignment and endianness.
