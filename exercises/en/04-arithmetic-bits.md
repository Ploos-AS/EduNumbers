# Exercises: arithmetic and bit operations

1. Add `A7₁₆ + 6D₁₆` as 8-bit and state the carry.
2. What happens with signed overflow in `64₁₆ + 32₁₆` as int8?
3. Calculate `55₁₆ XOR FF₁₆`.
4. Calculate `A5₁₆ AND 0F₁₆`.
5. Shift `00110110₂` one position left and right logically.
6. Create a mask for bits 1, 4, and 7.
7. Describe how to set bit 4, clear bit 1, and test bit 7.
8. Why must NOT always be interpreted with a known bit width?
