# Exercises: numbers in assembly

1. Explain the difference between an immediate value and a memory address.
2. In 6502-like syntax, what does `#` normally signal in `LDA #$7F`?
3. What is the decimal value of hex literal `0x2A`?
4. Why is `$100` problematic as a value in a pure 8-bit field?
5. What does mask `0x0F` do when ANDed with a byte?
6. Why can Intel and AT&T x86 assembly look different even when machine code expresses the same operation?
7. What can go wrong if a disassembler interprets a data table as code?
8. Find the signed and unsigned interpretations of 8-bit pattern `11111110₂`.
