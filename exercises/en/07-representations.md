# Exercises: other representations

1. Apply `g = b XOR (b >> 1)` to binary value `0110`.
2. Why can one-bit transitions be useful in a mechanical position encoder?
3. With excess-127, what real exponent does field value 140 represent?
4. With excess-15, what field value stores exponent −4?
5. What is the ASCII code for `A` in decimal and hex?
6. Explain the difference between a Unicode code point and UTF-8 bytes.
7. A register uses bit 7 as READY and bit 0 as ENABLE. Which mask tests both bits at once?
8. Give three plausible interpretations of byte `0x41`.
