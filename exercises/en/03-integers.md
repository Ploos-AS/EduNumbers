# Exercises: integer representation

1. Find the unsigned range for 10 bits.
2. Interpret `FE₁₆` as unsigned 8-bit and signed 8-bit two's complement.
3. Write −42 as 8-bit two's complement in binary and hex.
4. What is `250 + 20` if only eight bits are retained?
5. Explain the difference between carry and signed overflow.
6. Why can signed 8-bit represent −128 but not +128?
7. What is `7F₁₆ + 01₁₆` as signed 8-bit, and why is the result problematic?
