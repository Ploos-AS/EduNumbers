# Løsninger: andre representasjoner

1. `0110 XOR 0011 = 0101`.
2. Når bare én bit endres mellom naboposisjoner reduseres risikoen for tvetydige mellomtilstander dersom bitene ikke skifter helt samtidig.
3. (140-127=13).
4. (-4+15=11), altså feltverdien 11.
5. 65 desimalt, `0x41`.
6. Code point er Unicode-identiteten til tegnet; UTF-8 er en konkret variabel-lengde byteencoding av code pointet.
7. `10000001₂ = 0x81`.
8. For eksempel unsigned heltall 65, ASCII-tegnet A eller et rått bytefelt i en instruksjon/protokoll/filstruktur.
