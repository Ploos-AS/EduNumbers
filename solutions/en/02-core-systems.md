# Solutions: core number systems

1. `11010110₂ = D6₁₆ = 214₁₀`.
2. `7B₁₆ = 01111011₂ = 123₁₀`.
3. `345₈ = 011 100 101₂ = 229₁₀`.
4. `100₁₀ = 1100100₂ = 144₈ = 64₁₆`.
5. `2^12 = 4096` possible values.
6. `2^12 - 1 = 4095`.
7. Four bits have `2^4 = 16` patterns, exactly the number of digits in base 16.
8. 4 KiB is 4096 bytes; 4 kB is 4000 bytes.
