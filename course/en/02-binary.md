# Binary: base 2

Binary uses only 0 and 1. Each position has a power-of-two weight.

## PREDICT

What decimal value does `10110₂` represent?

## STEP

From right to left the weights are 1, 2, 4, 8, 16 and so on. Thus `10110₂ = 16 + 4 + 2 = 22₁₀`.

A binary digit is a **bit**. Eight bits are commonly grouped into a byte. Wider machine values are often described as words or by an explicit bit width.

## OBSERVE

With (n) bits there are (2^n) possible patterns. Four bits give 16 patterns; eight bits give 256.

## EXPLAIN

Binary is useful because digital hardware can reliably distinguish two states. The representation maps naturally to switches, logic levels, registers and memory.
